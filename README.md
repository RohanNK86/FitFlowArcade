🛍️ E-Commerce Website - FitFlow

A modern, responsive E-Commerce website built using HTML, CSS, and JavaScript.
The project focuses on performance optimization, responsive design, and modern UI aesthetics.

This website demonstrates how a lightweight front-end store can deliver a smooth shopping experience while maintaining fast load times and clean design principles.

🚀 Features

🛒 Modern E-commerce style product layout

📱 Fully Responsive Design (Mobile, Tablet, Desktop)

⚡ Lazy Loading Images to reduce HTTP requests and improve page load performance

🎨 Glassmorphism UI Effects for a modern and elegant interface

🖼️ Product images integrated for a visually engaging storefront

🧭 Smooth navigation and clean UI layout

⚡ Optimized CSS and JavaScript for faster performance

🛠️ Technologies Used

HTML5

CSS3

JavaScript (Vanilla JS)

Responsive design techniques

Lazy loading optimization

## Demo backend

Run the local backend with:

```bash
npm start
```

Open `http://localhost:3000`, register an account, add a product to the cart,
and place an order. The **Account** button lists the user's orders and tracking
status. Demo orders move from **confirmed** to **packed**, **out for delivery**,
and **delivered** every 15 seconds so the flow can be tested without a payment
or delivery service. Users and orders are stored in `data/store.json`, which is
created automatically and ignored by Git.

Several techniques were used to improve website performance:

Optimized CSS & JavaScript

These improvements help ensure faster loading times and smoother user experience.
